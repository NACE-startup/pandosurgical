
  # Pando Surgical Website

  Marketing site for Pando Surgical (Next.js App Router, TypeScript, Tailwind v4). Multi-page: Home, Product, Team, Company, Investors, Contact, plus an internal Firebase-backed team dashboard behind login.

  ## Running the code

  Run `npm install` to install the dependencies.

  Copy `.env.example` to `.env.local` and fill in Firebase/EmailJS values to enable auth, the dashboard, and the contact form.

  Run `npm run dev` to start the development server.

  Run `npm run build` && `npm run start` to build and serve a production build locally.
